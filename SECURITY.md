# Security reports

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/k4black/fastapi-jwt/security/advisories/new).
Use that form instead of a personal email address.

See [published security advisories](https://github.com/k4black/fastapi-jwt/security/advisories) for affected versions and fixes.

Version 0.3.1 fixes access-token type validation and authentication error handling.
Python support, JWT backend support, and cookie defaults remain unchanged from 0.3.0.
The python-jose removal and other breaking changes are reserved for version 0.4.0.
